# Salcara AI v1.3.2

## 统一对话与图片创作

- 默认使用一个 ChatGPT 风格输入框，自动判断每条消息是普通对话、图片/文件分析、图片生成还是图片编辑。
- 图片只是示意时不会触发生图；“分析、识别、描述、总结”等请求只发送到对话服务商。
- 明确要求生成或修改图片时，先由独立对话 API 检查并整理作图要求，再调用图片 API；对话步骤失败不会继续发起付费生图。
- 在同一会话上传 PDF/Word 并分析后，下一条明确的生图请求会沿用历史文件上下文。
- 保留“仅对话”和“仅图片创作”手动覆盖，兼容旧会话和只配置 Images API 的高级用法。

## 配置与安全

- 对话服务商和图片服务商可以使用完全不同的地址、密钥和模型。
- 自动生图找不到对话模型时会在付费图片请求前停止并提示配置，不会盲目扣费。
- 已保存的作图说明会用于手动重试，避免重复解析；图片 URL 下载失败只重试下载，不重新提交生图。
