## 明确的限制

- 当前 Bridge 只在 Windows / Linux 声明文件、终端和预览能力；macOS 的部分底层实现不等于已经开放这些功能。文件句柄授权验证未支持的系统不会使用路径猜测兜底。
- 文件仅支持已授权项目中的 **UTF-8 文本文件，单文件最多 128 KiB**。受文件名/类型白名单约束；不允许路径穿越、敏感隐藏路径或链接绕过；不提供目录管理、二进制编辑或任意跨目录移动。
- 自动撤销仍要求完整、可验证的变更与精确当前版本；不支持二进制、不完整差异、无法确认末尾换行或当前内容不再匹配的变更，不强制覆盖复杂重命名链。一次最多预检 24 个文件、100 条原始修改记录。
- 文件草稿持久化，最多 8 个文件、1 MiB 文本内容（包含原始基准文本）。超额会明确拒绝本次输入，保留已接受草稿；不会静默淘汰旧草稿。成功保存、恢复为原始内容或用户明确丢弃才释放该条记录。恢复终端标签不会自动恢复执行，需用户明确重新打开。
- 电脑预览是**可交互的画面传输，不是手机内完整 DOM 浏览器**。已加入文字选择/复制、弹窗、上传/下载、按键修饰键、网页结构查看及区域批注；结构查看不是完整 DevTools，区域批注没有实时 DOM/CSS 样式编辑。真实控制仍限电脑 loopback 页面；公网 WebView/iframe 仍受嵌入策略约束。
- 预览截图为 JPEG，base64 字段上限 220 KiB；当前视口范围为 320–1440 × 240–1200。过大的画面会返回明确错误，不会冒充加载成功。
- 终端和电脑预览均最多 4 个；90 秒未收到对应活动请求会回收。切换标签可以保留实例；关闭标签结束对应实例。撤权、会话变化、断连或进程退出会停止旧操作，不向新电脑重放旧输入。
- 终端输出为 512 KiB 有界回放，每次最多返回 48 KiB；较早输出被截断时显示提示。输入使用序号避免重放，失败或结果不确定时不会把重发当作新的安全执行。
- CLI 与 desktop 使用各自实际授权入口；只读历史不会因为存在这些 UI 按钮而获得写文件、终端或预览权限。
- Work 原生历史的图片操作只采用电脑明确返回的状态。原生 `imageView` 没有执行状态时，以“图片查看记录 · 电脑未提供执行状态”的中性提示保留原始位置，不冒充查看成功；这类状态未确认的历史图片记录目前不显示缩略图。未知或缺失状态的图片生成记录同样显示提示，不会产生非法工具事件而阻断整页历史。明确状态的图片操作保留工具行，缩略图仅来自实际可读取并通过校验的图片输出。
