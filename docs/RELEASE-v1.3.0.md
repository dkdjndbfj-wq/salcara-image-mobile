# Salcara AI v1.3.0

这版把应用从“生图工具”重新定位为通用 Android AI 客户端：默认进入对话，图片创作是可切换的独立模式。

## 主要变化

- 默认首页改为简洁的 ChatGPT 风格对话界面，侧边栏管理新会话和历史会话。
- 服务商设置改为列表页 + 分组编辑页：对话能力、图片创作能力和高级解析关联分开配置。
- 侧边栏新增独立的应用设置入口，服务商、当前模式、网络诊断和版本更新各自分层。
- 系统文件选择器改为通用入口，支持图片、PDF、Word、Excel、PPT、ODF、代码、文本、压缩包和未知文件。
- TXT/Markdown/CSV/代码等文本在本地读取；DOCX/XLSX/PPTX/ODF/EPUB 等 ZIP 文档在本地提取可见正文；压缩包只读取目录，不执行内容。
- PDF 继续在 Android 私有目录逐页渲染为图片，避免兼容网关忽略原始 PDF；每份最多 12 页。
- Responses 和兼容 Chat Completions 协议支持通用文件块；Claude Messages 对不支持的通用文件显示安全元数据，不伪造解析结果。
- 文件型图片会自动转换成 PNG/JPEG/WebP 参考图，沿用相册、相机、排序和蒙版编辑流程。
- 继续保留图片连续修改、上一张结果自动作为参考、透明背景、实际尺寸提示、保存和分享。
- 更新为版本 `1.3.0`、Android `versionCode 8`。

## 限制与计费提示

每次最多 4 张图片和 4 个文件；单个附件 20MB，合计 30MB。图片模式中的文件辅助生图仍然是“文件解析 + 生图”两次请求，可能分别计费。应用不会自动切换模型或协议重发付费请求。

## 隐私

密钥继续保存在 Android SecureStore；文件和历史保存在应用私有目录与 SQLite。办公文档解析在本地完成，无法本地解析的未知文件只会在所选协议支持时作为文件块发送给用户配置的服务商。
