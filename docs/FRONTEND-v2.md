# 界面与品牌（v1.4.0）

目标是商业级产品的质感，而不是工具面板：白色为主的界面，淡蓝渐变只出现在品牌和关键时刻。

## 品牌

- **Logo**：蓝色与粉紫渐变的双 S 丝带造型。原图为 `assets/brand-logo-source.png`，去底后的透明版本为 `assets/brand-logo.png`，应用内标志直接使用这张图。`npm run icons` 会据此重新生成启动图标、Android 自适应图标（含单色主题图标）、启动页与 favicon。
- **AI 思考**：Logo 缓慢旋转、呼吸（`LivingMark`），由于造型是二重对称，循环无缝。
- **色彩**：取自 Logo —— 天蓝 `#7CC6FF`、主蓝 `#3D7BFA`、紫 `#A68BF7`、粉 `#F4A6CE`、蜜桃 `#FFD9BD`。设计令牌集中在 `src/theme.ts`；主按钮、发送键、问候语与画图柔光都使用这组渐变。
- **图标**：`src/components/Icon.tsx` 是应用自有的 SVG 图标集（24 栅格、1.7 圆角描边），全应用只用这一套。

## 体验

- 首次打开是欢迎页（Logo、一句话介绍、三条卖点、“开始使用”），之后进入连接服务。
- 首页：渐变问候语 + 大字副标题，底部横向灵感卡片。
- 顶部只保留菜单、“Salcara + 当前模型”（点开切换）和新对话；模型 ID 以友好名称显示（如 Claude Sonnet 4.5）。
- 消息：用户为浅蓝圆角气泡；AI 回复全宽排版，下方是一排轻量操作图标（保存、分享、复制、重新生成）。不显示耗时、模型 ID 等技术信息。
- 画图时显示流动的柔光画布，完成后图片淡入。
- 输入框：圆角浮层，左侧“＋”打开相机 / 照片 / 文件面板，右侧渐变发送键；生成中变为停止键。
- 侧边栏：搜索 + 新对话，会话按时间分组，长按可重命名 / 删除。
- 设置、服务、模型采用分组列表，模型面板可直接调整默认画幅、清晰度、画质。
- 图片预览为沉浸式深色背景。
