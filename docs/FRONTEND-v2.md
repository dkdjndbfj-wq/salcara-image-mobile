# 新版会话与创作技能

界面以一个会话和输入框承载问答、图片理解、文件分析、图片创作。服务商在设置中管理；对话模型和图片模型分别选择，可以使用不同 API 与密钥。

## 技能如何使用

输入区的“技能”可以选择通用创作、参考图修改或海报排版。选择后只会添加一个可移除的标签，不会发出请求。用户输入要求并发送后，应用使用当前选择的对话服务商检查、整理方案，再调用图片服务商。图片模型、画质、尺寸和透明背景沿用用户设置。

普通相册和文件附件不会自动启用技能。分析图片、解释文件或明确要求“暂不生成”时使用对话 API。“先分析文件，再生成海报”可在同一轮完成分析与创作。历史图片的“引用创作”会加入参考图并选中参考图修改技能，仍需用户发送才执行。

技能检查结果、版本、最终提示词与参数随消息保存。图片请求失败后手动重试会复用已保存的方案，不会再次解析同一份资料。图片已生成但下载失败时，只重新下载。检查未完成、方案格式错误或参考图修改缺少主图时，不调用图片接口。

## 文字与当前限制

短艺术标题、装饰口号可以由图片模型生成。大量正文、价格、日期、联系方式和表格会保留原文，并在图片中预留干净位置；对应的排版方案显示在消息内。

**当前版本尚未实现本地文字叠排。** 预留区域和排版说明不等于文字已经出现在图片上，精确正文仍需后期添加。

目前技能为应用内置的三套创作指导，不会下载或执行桌面 `SKILL.md` 中的脚本，也不会远程导入任意代码。对话检查与图片生成是两次独立 API 请求，具体计费由服务商决定。
