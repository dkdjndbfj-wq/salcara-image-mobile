# 手机远程编程

[产品首页](../README.md) · [手机使用教程](USER-GUIDE.zh.md)

## 准备

先在电脑完成两件事：

1. 安装 [Salcara Desktop 正式版](https://github.com/dkdjndbfj-wq/salcara-desktop/releases)。Codex、Claude Code 或 Claude Desktop 需要另外安装。
2. 在电脑的 API 密钥库添加服务商地址、密钥和名称；在 Agent 卡片中选择 API，并配置允许远程使用的项目。

具体操作见 [桌面使用教程](https://github.com/dkdjndbfj-wq/salcara-desktop/blob/main/docs/USER-GUIDE.zh.md)。

远程编程有两种连接方式：通过兼容的 [Salcara Hub](https://github.com/dkdjndbfj-wq/salcara-hub-plugin) 中继，或在手机和电脑位于同一局域网／VPN 时使用电脑端的 TLS 直连。直连模式不需要 Hub，也不会在直连失败时自动切换到 Hub；不是任何提供模型 API 的网站都已经启用了 Hub 远程功能。

1.8.0 手机内“下载电脑端”仍指向 GitHub 首页，下载时请使用上面的正式桌面链接。本次文档整理没有改变已发布 APK 的按钮行为。

## 1. 进入编程首页

从手机进入 **编程**，先看到电脑、Agent、API 密钥和最近任务等入口。未绑定电脑也可以看到首页；只有要进行远程操作时才需要绑定。

## 2. 绑定电脑

1. 在电脑打开 **手机远程**。使用 Hub 中继时先连接兼容的 Hub 站点；使用局域网／VPN 直连时直接启动 **电脑直连**，生成直连二维码。
2. 手机在编程首页点击 **连接电脑**；已有设备时，在设备管理右上角点击扫描图标。
3. 直接扫描电脑二维码，应用会读取站点并检查兼容性，无需手动填写中转站网址。Bot 连接入口在扫码页面底部。
4. 绑定完成后返回首页，核对当前电脑和连接状态。

新配对使用设备凭证，不需要在手机填写模型 API Key、Hub 管理密钥或中转站用户账号。二维码有时限且只能使用一次，失效后在电脑重新生成。不要把二维码发到群或公开 Issue。

每台电脑首次绑定只扫描一次。后续启动、断线恢复和切换已保存的电脑使用原绑定。支持 `pair.connections.v1` 的手机、电脑和 Hub 会同步这台电脑已保存的中转站连接，各站使用独立凭证；离线站点稍后重试，不影响已成功的绑定。新增站点仍须先在电脑端完成接入，API Key 相同不代表另一台电脑或另一站点自动获得授权。旧版本不支持自动同步时需更新相关组件。

设备管理以卡片显示已绑定电脑，可切换、编辑备注名或删除设备。切换后返回首页，API、Agent、项目、会话、模型及工具页全部跟随当前电脑。删除设备会处理这台电脑的各站绑定；重新绑定才需要再次扫码。

## 3. 选择 Agent 和电脑 API

1. 在编程首页确认当前电脑，选择 **Code** 或 **Work**。需要换电脑时先使用首页电脑入口。
2. 点击 Codex、Claude Code 或 Claude Desktop，直接进入这台电脑、这个 Agent 对应分类的 **项目与会话**，不再重复选择电脑或经过“准备连接”。
3. 点击会话进入对话界面；首页最近记录和目录使用相同分类。助手、聊天、编程三个顶部入口只在首页显示。

编程中的 API 密钥页只读取电脑密钥库的名称和模型元数据，不把电脑 Key 明文取回手机。新增、改名、修改地址或密钥在电脑端完成，再在手机刷新。

API 名称是你给服务商配置起的标签，不是模型，也不专属于某个 Agent。一个 API 可以供不同工具选择，但能否使用某个模型取决于接口兼容和工具调用能力。

## 4. 读取历史与继续对话

会话先按 **Code / Work** 分类，再按当前电脑上的项目目录分组，同一项目可包含多个对话；未关联工作目录的已有会话归在“临时任务”。新建任务沿用当前分类，并仍须选择电脑已授权的项目文件夹。分类随新任务回执、电脑会话列表、历史打开和实时更新传递；切换电脑会切换到那台电脑自己的目录，即使会话句柄相同也不会混用。可搜索或继续加载更多记录。点开已有会话会读取它的历史，不因“打开”而新建任务或切换 API。

在支持继续操作的会话里，输入内容发送给电脑上的 Agent；新任务则选择电脑允许的项目，再提交任务。回答、工作步骤、文件变更、耗时和子智能体活动以电脑实际报告的数据为准，相关细节可在活动／摘要入口查看，不要求所有工具都输出同样的信息。

Agent 提问或需要批准操作时，使用出现的问答／审批入口处理。提交后查看发送状态；不支持的原生请求仍需在电脑上处理。不能把“已在手机点提交”当作电脑已经收到。

手机上的“在电脑上打开”用于回到原工具中的会话，电脑窗口不保证即时同步手机续聊结果。电脑项目和原 Agent 历史仍属于电脑，手机缓存不是它们的完整备份。直连模式下，输入、审批和事件通过已配对的 TLS WebSocket 到达这台电脑；断线时请求会失败并显示直连状态，不会改走 Hub。

## 5. 切换 API 与模型

首页 **API 管理** 显示当前电脑的密钥库，以及各 Agent 正在使用的 API。会话目录的 API 按钮直接打开同一个管理页面，关闭后回到原目录；更多菜单中的 **切换 Agent** 返回首页选择，不再进入旧连接向导。点击对应 Agent 的 **更换 API**，选择电脑已保存的密钥，或选择 **跟随电脑** 恢复电脑设置。共用 API 设置的 Agent 会明确标注关联关系。

切换后会再次读取电脑状态。只有配置已就绪且与目标一致时才显示 **已同步**；命令无回执、电脑仍在切换或回读失败时保留 **待确认**，可点击核对按钮或右上角刷新。关闭页面、检查另一个 Agent 或暂时切换电脑不会清除未确认目标。离线时保留缓存并禁用切换，恢复连接后可以继续核对。此状态确认的是电脑配置，模型服务是否可用还需实际请求验证。

已进入对话时，也可在模型选择器的顶部 API 区域切换电脑保存的 API，下方选择该 API 可用的模型。

先等当前任务结束，再切换 API、模型或重启工具。收到电脑切换成功的确认后再发送下一条任务；正在处理、等待审批或仍有待确认消息时，不要强行重复切换。

另一把 Key 的模型可能不同，同一把 Key 的后台分组也可能改变。若旧模型已不可用，刷新当前 API 目录并重新选可用模型，不要仅凭旧缓存继续提交。推理强度只在 Agent 与模型实际支持时可用。

## 6. 断网、离线与提醒

顶端状态是连接的简要提示。不能连接时，按顺序检查手机网络、Hub 地址和电脑是否运行桌面 App／是否休眠。看到缓存历史并不代表电脑此刻在线。

网络短暂中断时，兼容链路会继续核对原请求和补齐进度。无法确定是否送达、超过安全确认期限或站点不支持安全重试时，应用停止自动重发；先刷新原会话核对，再决定下一步，避免重复发布同一任务。

离开页面不等于停止电脑上的任务。停止必须使用支持的停止操作并确认结果；电脑离线时不能保证停止指令立即生效。

通知受 Android 权限、系统电池管理和部署配置影响。后台待命是可选的，会保留后台连接并消耗一定电量和服务器资源；未开启或应用被系统终止时，不保证及时提醒，重新进入应用后核对任务状态。

通知菜单会区分「已开启后台待命」和实际服务运行状态；服务未运行时可点「重新连接任务提醒」。Android 系统回收进程后，如果允许重启服务，会从本机加密检查点恢复；强行停止、重启手机或厂商限制后仍需重新打开 App。任务观察最长 2 小时，后台待命恢复凭据最长 7 天，打开 App 后再次退到后台会续期。关闭通知或解除当前配对会清除检查点；直接连接电脑的模式没有 Hub 服务端推送。

## 7. 当前支持范围

| 类型 | 可以如何使用 |
| --- | --- |
| Codex 编程会话 | 通过支持的后端读取和继续 App／CLI／IDE 编程记录；原生桌面接口受版本及授权限制 |
| Claude Code | 读取兼容记录，继续支持的编程会话 |
| Claude Desktop Code | 通过 Claude Code 后端继续，不冒充普通 Chat 的原生发送 |
| Claude Desktop Chat / Cowork | 兼容的本地历史读取；不支持原生远程发送或停止 |

实际能力以电脑报告为准，不通过换 API 或普通重启解锁官方未提供的桌面接口。这里不是远程桌面，不能在手机控制电脑的任意窗口。

## 手机直接使用电脑前端

右侧工作区按网页建立独立标签。用户主动点击对话链接或打开新网页时，选中对应标签并展开
工作区；电脑 Agent 成功完成明确的浏览器打开或导航操作时，手机只在后台同步标签，保持
当前对话、当前标签以及侧栏展开状态。重复收到同一操作不会重复创建标签，有稳定页面 ID
的后续导航更新原标签。普通消息中的网址、网页搜索和失败的工具调用不会自动打开网页。

每个网页分别保留地址草稿、页面实例和已知导航记录，切换标签或折叠工作区不会重建网页；
关闭标签后释放页面。更换电脑、Agent 或会话时，网页也按对应工作区隔离。同步依赖电脑端
支持并报告结构化浏览器事件，不能监控电脑任意浏览器窗口，也不会复制桌面登录 Cookie。

如果打开的是局域网或 VPN 可达的前端地址，手机会在右侧工具栏内嵌显示它。你在
页面中点击、输入或提交表单时，请求直接回到电脑上运行的前端服务，所以交互效果等同于
在电脑浏览器打开这个页面；它不经过 Salcara Hub，也不会改变手机的对话回执。
原生手机端使用独立无痕上下文，不共享手机浏览器 Cookie，地址中不会附带 API Key 或配对凭证。

内嵌页面只接受 HTTP(S) 地址，新窗口在支持的页面上创建独立标签。网页预览版受浏览器
同源策略影响，不能读取跨域页面的内部地址、历史或拦截其所有新窗口；禁止内嵌的网站需
使用“在系统浏览器打开”。`localhost`、
`127.0.0.1`、Docker 内部地址和仅绑定电脑本机的端口无法从手机直接访问，手机会保留浏览器
入口或提示服务不可达。Docker、数据库和其他重型运行时仍在电脑执行，手机只查看其前端结果。
当前没有任意端口代理或公网 NAT 穿透；若以后要展示电脑 localhost，需要另行设计短期、绑定
会话和设备的预览租约，不能复用配对 token 或开放通用代理。

## 安全

只配对自己的电脑；使用 Hub 中继时只连接自己管理或信任的 Hub。Hub 模式的消息中继不是端到端加密，Hub 运营者可能接触会话、附件、项目路径和任务内容；直连模式不经过 Hub，但仍应只在自己信任的局域网或 VPN 上使用。电脑远程权限应只开放需要的项目，Agent 的审批策略也需要按实际工作检查。

模型 API Key 与设备配对凭证用途不同。配对被撤销或设备被站点封禁时，先联系自己选择的站点管理员，不要在手机填写 Hub 管理密钥绕过限制。更多说明见 [隐私说明](../PRIVACY.md)。
