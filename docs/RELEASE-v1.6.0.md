# Salcara AI v1.6.0

Android `versionCode` 为 17，可直接覆盖安装 v1.5.0。服务商、密钥、会话和本地图片会保留。

## 聊天空间与记忆匣

- 新增独立的“聊天”空间，可创建角色并持续对话；与助手空间的会话分开保存。
- 每个角色有自己的分层对话记忆和记忆匣，支持查看、搜索、编辑、删除及导出为 Obsidian Markdown。
- 角色可按设置使用对话、图片、联网和 Live 语音能力；记忆整理可单独配置或关闭。

## 更多模型与工具

- 新增可配置的智能体、工具箱和工具调用步骤展示；支持按需配置工具、搜索与文件能力。
- 增加语音服务商与协议选项，语音识别、语音合成和实时语音可分别配置。
- 增加自定义图片画幅。除常用比例外，可输入比例或宽高；使用前会按模型允许的尺寸规则校验。
- 增加更多文件预览、个人化设置和 Live 界面资源。

## 兼容性与修复

- 保留 v1.5.0 的服务商、密钥、会话和图片，可覆盖安装升级。
- 修复语音供应商测试中的 Jest mock 初始化问题，并通过类型检查和自动化测试。

## 权限

语音功能按需使用麦克风。手机操作功能只有在用户确认相应卡片后才会调用 Android 系统功能。
