# Salcara Image v1.2.0

## 新增

- 图片创作 / 对话解析模式，支持兼容 Chat Completions 与 Responses 的服务商。
- 识图和 PDF、TXT、Markdown、CSV 资料解析；支持文件辅助生图。
- 生图分组可绑定单独的对话服务商，不必更换当前会话。
- 连续对话携带最近 12 轮成功消息与相关生成图；支持复制回答。
- 侧边栏网络诊断，不调用付费模型即可排查 API 和图片域名连接。

## 修复与安全

- 图片下载采用流式传输与限时重试；取消或超时保留原图片链接，重新下载不重复生图。
- 文件解析失败不会继续生图；解析完成后保存说明，重试时复用。
- 更新检查只接受已发布版本；备用清单在 APK 发布后生成，避免未发布版本误报。
- 安装前验证 APK 大小与 SHA-256；密钥请求禁止跨域重定向。
- 原有会话、图片、密钥通过增量数据库升级保留，Android versionCode 升至 6。

## 重要说明

网站、API 和图片图床可能是不同域名。sub2api 管理员应在生图上游账号开启「生图结果 URL 转 base64」，由中转服务器获取图片后返回给手机。新版 App 不会自动修改服务器；不同运营商的直连能力仍需实测。详见 [网络说明](./NETWORK.md)。

PDF 和视觉输入依赖所选模型及服务商支持。文件辅助生图包含「解析 + 生图」两次分别计费的请求。每次最多 4 张图片和 4 份文档，单个不超过 20MB、合计不超过 30MB。无自动付费请求重试。

安装请使用同签名 APK 覆盖旧版，不要卸载旧版，以保留手机本地数据。
