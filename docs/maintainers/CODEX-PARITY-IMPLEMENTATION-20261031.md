### 已实现的使用流程

- **图片画布**：主对话顶部文件图标 → 对话产物 → 图片画布；点正文图片也可直接聚焦。聚合当前会话的真实图片，支持网格、多选、逐张查看、拖动框选区域与批注。保留原消息、附件、文件版本和归一化区域；批注只追加至原会话草稿，由用户确认发送。电脑或会话切换后旧回调失效，子任务图片不混入父会话。存储失败提示并允许重试，未保存批注不被失败读取覆盖。
- **产物查看器**：文件链接或产物列表打开 PDF、DOCX、XLSX、PPTX、HTML、SVG 与文本。PDF 用本地 PDF.js 实际渲染、翻页、缩放及选择文字；Office 提供段落/表格、工作表/单元格、幻灯片内容导航。下载和分享使用原始文件内容，不把预览结果冒充原文件。
- **编辑与保存**：HTML、SVG、Markdown、TXT、JSON 可查看源码并编辑；草稿按来源及文件版本保存。保存带 expectedRevision，电脑版本冲突保留草稿且不覆盖；关闭或刷新有未保存内容时需确认丢弃。未保存预览不允许生成错误归属版本的批注。PDF 页码、表格工作表/单元格及原文引用随批注加入原草稿。
- **正文交互内容**：完整的 html / interactive-html / visualization / svg 代码块可以直接预览，未闭合块继续显示源码；不自动执行 JSX。支持控件、自定义状态恢复和显式选取批注。状态按电脑、Agent、API、项目、Code/Work、会话、消息及源码版本隔离，旧版本批注不能套用到新版本。Agent 新生成内容不会自动抢占画布焦点。

## 文件汇总的完成时机（2026-11-07）

“已编辑文件 / 撤销 / 查看变更”汇总卡只在对应整轮及子任务结束后显示。执行期间保留原本的简洁文件编辑行；单次编辑完成、进度回复或暂时没有运行命令都不代表整轮完成。主会话与 Direct 共用判定，已经结束的历史轮次保留汇总。
