# 手机端 Codex 风格会话侧栏（2026-10-10）

## 目标

在手机端打开一个远程会话时，提供一个可随时收起的会话导航抽屉。它复用电脑返回的会话句柄和现有目录缓存，不创建新的任务、不改变当前 API，也不启动常驻轮询。

## 调查依据

导航依据是 [Codex App Server](https://learn.chatgpt.com/docs/app-server) 及电脑适配器实际返回的目录和子会话句柄，不用云端 Agents API 代替本机桌面接口。本实现沿用 Salcara 现有组件和官方 Agent 图标资源，不声称像素级复制闭源 UI。完整核对与本轮边界修复见 [2026-10-11 审查清单](REMOTE-CONVERSATION-FEATURE-AUDIT-20261011.md)。

## 已实现

- 对话页顶部增加“打开侧边栏”按钮，入口不改变当前会话。
- 左侧抽屉包含当前 Agent/电脑标识、搜索、新对话、置顶/最近或项目分组目录、当前选中态和离线缓存提示。
- 普通目录和 Codex 原生桌面目录都使用现有分页游标；用户点“更多对话”才请求下一页，避免打开侧栏就读取全部历史。
- 主对话中的子智能体链接只打开侧栏并定位真实句柄；点已授权行才导航。原生未知子任务不通过 CLI 读取或执行。
- 子智能体行使用 `AgentBrand`/`ToolBadge` 的官方 Codex、Claude 图标。未知扩展 Agent 使用中性图标，不把未知工具伪装成 Codex 或 Claude。
- 子会话句柄允许显示有界扩展命名空间；同族适配器可导航，跨族任务没有明确 Agent 契约时禁用，不沿用父 Agent 发送。
- 侧栏关闭按钮和背景遮罩都可关闭；关闭后不留下覆盖输入框的绝对层。

## 资源与一致性边界

- 侧栏只在用户打开时触发目录读取；没有新增定时刷新或长连接。
- 电脑离线时只显示已经在手机状态/缓存中的目录，不能凭标题伪造可发送权限。
- 当前 API、模型和会话正文仍由 `ThreadView` 管理；侧栏只负责导航，避免切换目录时篡改 API 或重放消息。
- 读到的子会话没有标题时，显示有界的句柄尾部作为区分；句柄本身不作为凭据展示。

## 尚未承诺

- 公开文档没有提供 Codex 桌面应用私有的像素级布局、拖拽排序或同步滚动规范；因此尚未声称与官方桌面 UI 完全一致。
- 没有真实 Codex/Claude 账号、真实 Hub 或真机网络验收；测试使用合成状态，真实 Agent 能力仍以电脑 Bridge 返回的 capabilities 为准。
