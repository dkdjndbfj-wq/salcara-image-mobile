# Salcara Android 1.8.5

本版完善 Bot 远程连接恢复与通知路由，配套 **Salcara Desktop 1.6.8** 与 **Salcara Hub 0.5.5**。

- Bot 组暂时没有在线电脑时保留组连接；绑定回包丢失后可查询并恢复已确认结果，不盲目重复绑定或执行任务。
- 完善多电脑的目标选择、发送回执与任务事件恢复；仅收到回执时不会重新执行任务，撤销授权后不再继续发送。
- Hub 地址迁移时保留原站点身份与组范围，先验证新入口确属原站点，再恢复授权请求；身份不符、旧令牌或已撤销授权不能借恢复流程重新生效。
- 改进 Android 通知的多电脑路由、前后台交接及重试状态；未经验证的路线保留为可重试，避免临时故障造成永久漏收。
- 收紧最终发送时的授权检查，前台和原生后台使用一致的路由与身份约束，避免切换连接或撤销期间的迟到结果发往错误目标。

正式包名仍为 `top.salcara.image`，版本 1.8.5（Android versionCode 26；iOS 源码 buildNumber 26）。正式 Android 构建沿用现有发布签名，并核验与 1.8.4 的覆盖升级兼容性。已安装正式版时无需先卸载；建议先备份重要本地数据。

## 验证与使用边界

本轮已完成 JavaScript、类型检查、Android 原生逻辑及隔离 TLS 联调；联调用合成 Agent 验证恢复、迁址、回执、撤销与多电脑路由，不等同于所有真实 Agent 或安卓真机验收。正式 Android 包已通过完整构建、原字节产物校验与同签名覆盖升级检查，并已发布。

电脑需自行安装并配置相应 Agent，各 Agent 的发送、模型、历史和工具能力依实际支持情况开放；本版不接管 Claude 账号登录。Android 后台通知仍受系统、省电、网络及站点推送配置影响，不能保证强制停止后即时送达。锁屏、省电、真实推送及真机安装体验需在实际设备确认。本版不提供新的正式 iPhone 安装渠道。
