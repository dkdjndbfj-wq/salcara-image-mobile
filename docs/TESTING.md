# 测试说明

## 自动测试

```bash
npm run typecheck
npm test
npx expo-doctor
```

当前单元测试覆盖 URL 规范化、模型列表筛选、画质限制、九种尺寸、透明参数、生成/编辑字段、Base64/URL 结果保存与敏感信息脱敏。

## 真机验收清单

- 新建、编辑、切换和删除多个服务商
- 首次未选择模型/画质/比例/清晰度时不能保存
- 新会话的透明按钮默认关闭，开启后只在当前会话保持高亮
- 相册、拍照、文件各添加图片；四张上限；长按拖动排序
- 历史生成图片“作为参考图”
- 蒙版画笔、橡皮擦、大小、撤销、重做、清空和确认
- 文生图、四图编辑与蒙版编辑
- 取消、10 分钟超时、400、401/403、404、429、5xx 与手动重试
- 保存到相册、系统分享、删除会话时清理本地文件
- 生成期间保持屏幕唤醒；强制结束应用后任务显示“已中断”

真实接口验收不得自动重试，统一提示词“奥特曼打怪兽”，最多三次：普通生成、透明背景生成、参考图蒙版编辑。验收密钥必须在发布前轮换。
