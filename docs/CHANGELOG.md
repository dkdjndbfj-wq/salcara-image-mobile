## 需要保留的历史边界

- 原说明反复要求同签名覆盖安装，不卸载以保留本地数据。附件、视觉、语音及工具支持依赖实际模型/API。
- 文件解析、摘要、语音与图片生成可能分别产生费用；HTTP 没有返回 usage 不代表免费。未知送达时不能盲目重发收费生成请求。
- 1.5.0 旧说明中的“只有本站 API 用户才能远程”“macOS 已提供正式桌面包”等不能作为现行产品承诺。当前设备配对与模型 API 分开，远程范围见 [远程编程教程](REMOTE-PROGRAMMING.zh.md)。
- 早期“手机已可控制全部桌面聊天”的笼统表述不准确。Codex 原生能力需接口兼容及授权；Claude Desktop 普通 Chat/Cowork 不提供直接发送/停止，不用 Claude Code 冒充原桌面。
- iOS 源码、交叉构建、未签名 IPA 和 Android 测试通过不能互相代替设备验收。现行安装入口以项目首页为准。

完整旧说明可从各历史标签或提交查看；本地删除前另有逐文件备份。当前 `RELEASE-v1.8.0.md` 仍保留在原路径，供现有发布流程使用。
