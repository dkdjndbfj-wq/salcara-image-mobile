# Salcara AI 使用教程

[产品首页](../README.md) · [远程编程](REMOTE-PROGRAMMING.zh.md) · [文档目录](README.md)

## 1. 安装与更新

从 [正式 Releases](https://github.com/dkdjndbfj-wq/salcara-image-mobile/releases) 下载 Android APK，而不是 Source code 或开发测试包。首次安装按 Android 提示为当前下载来源授权，安装后可收回该权限。

已有正式版请直接覆盖安装，不要先卸载。更新入口是“关于与更新”；确认下载后，应用校验包的大小和 SHA-256，最后仍需在系统安装器中确认。签名不一致时不要为了安装而先删除原应用，请核对下载来源。

当前正式版本是 1.8.1，包名为 top.salcara.image。尚无正式 iPhone 安装渠道，源码或未签名 IPA 不能当作可直接安装的 iPhone 应用。

## 2. 配置手机助手的 API

1. 打开 **设置 → API 管理**，添加 API。
2. 选择平台或兼容协议，填写服务商提供的地址与密钥。地址应是 API 地址，不是服务商的用户登录页。
3. 连接后读取模型目录，为对话、绘图或语音选择对应 API 和模型。无法读取目录时，只在服务商确认模型可用后手动填写模型 ID。
4. 回到助手，发送一个普通问题，确认所选 API 可用。

可以保存同一平台的多把 Key，也可以把对话、绘图、语音识别、语音合成和实时语音交给不同服务商。密钥没有通用的“最佳模型”：选项取决于该 Key 当前有权访问的模型。

使用生图独立分组时，绘图选这组 API；聊天、识图和文件分析另外选支持这些功能的对话 API。只配置绘图服务时，文字消息会直接用于图片生成，不等于具备聊天能力。

此处管理的是手机助手、聊天与语音使用的 API。**编程中的 API 来自电脑密钥库**，见 [远程编程教程](REMOTE-PROGRAMMING.zh.md)，不要把手机助手 API 当成设备登录凭证。

## 3. 对话、图片与文件

直接在助手输入文字，或用加号添加附件：

- “总结这份 PDF”：使用合适的对话／视觉模型分析文件。
- “画一张 9:16 的旅行海报”：具备工具调用能力的对话模型可以调用绘图服务。
- “把刚才那张改成夜景”：沿用会话中的图片作为参考。
- 上传照片后说“描述这张图片”或“参考它生成海报”：前者是视觉理解，后者需要图片创作能力。

一次最多添加 4 张图片、4 个文件。单个附件最多 20 MB，图片与文件合计最多 30 MB；编码后的请求还有体积限制，大文件需要缩小或拆分。

PDF 在手机本地逐页渲染成图片，每份最多 12 页，再发给支持视觉的模型；不是直接保证上游能读取原始 PDF。办公文件和文本尽可能在本地提取，压缩包只读取目录，不执行其中程序。出现超限、加密或格式错误时，先处理文件，不要反复提交。

图片外链下载失败时使用“重新下载”，不要把已生成的图片当成未生成重新请求。重新生成会调用图片 API，可能再次计费。透明背景、比例、质量和实际尺寸最终取决于服务商支持。

## 4. 语音与聊天伙伴

输入框麦克风用于语音输入，Live 用于语音交流。在语音设置中分别选择识别、合成或实时语音服务。

支持的 Android 设备可下载本地识别模型；它不需要把声音发给识别服务，但 AI 回答仍使用所选对话 API。设备不支持本地模型时选择云端识别。模型下载会占用手机存储，可在设置中删除。

切到聊天空间，可以建立不同聊天伙伴，每个角色有自己的会话和记忆匣。记忆在手机本地保存；整理、反思或向量检索会调用配置的模型服务，可能产生额外 API 费用。敏感内容不应仅依赖自动过滤保护，分享或导出前请自行检查。

## 5. 记录、导出与换手机

会话侧边栏可以查找、重命名和删除记录，也可以将对话导出为 Markdown。

在 **设置 → 备份与恢复** 生成备份文件，妥善保存到你选择的位置。备份包含普通对话、记忆、聊天伙伴及相关图片和文件；不包含 API Key、电脑配对或应用设置，也不是电脑项目／远程 Agent 记录的备份。

恢复采用合并方式，已有内容不会被覆盖删除。换手机后仍需重新添加手机 API，并重新扫码配对电脑。卸载可能清除本机记录，不要把重新安装当作备份方式。

## 6. 使用远程编程

普通手机对话不需要服务器。需要继续电脑上的任务时，打开 **编程** 首页，按 [远程编程教程](REMOTE-PROGRAMMING.zh.md) 准备桌面 App 和兼容 Hub，再扫码绑定。

## 7. 常见问题

| 情况 | 先检查什么 |
| --- | --- |
| Key 无效、额度不足 | 检查当前服务商账户和授权，必要时换 API；不要公开 Key |
| 模型列表有名字但请求失败 | 检查该 Key 的分组、协议及模型能力；目录不是功能保证 |
| API 地址可以打开，图片收不到 | API 和图片 CDN 是不同链路；见 [网络排错](NETWORK.md) |
| 生图分组不能聊天 | 为对话另选 API 和模型，不要用图片接口当聊天接口 |
| 无法下载更新 | 换可访问 GitHub 的网络或从正式 Releases 下载；不要使用不明 APK 镜像 |
| 原电脑窗口没马上刷新 | 查看原会话及“在电脑上打开”入口；不保证原生窗口实时同步 |

仍有问题可到 [GitHub Issues](https://github.com/dkdjndbfj-wq/salcara-image-mobile/issues) 反馈，附版本、设备系统和脱敏的操作步骤；不要上传 API Key、配对二维码、凭证或完整私人会话。
