# Salcara AI v1.3.3

## Cherry 风格的简洁工作区

- 主屏收敛为单一会话：顶部显示当前工作区，底部固定附件、输入和发送；自动、仅对话、仅图片创作放进紧凑底部弹层。
- 空会话改为轻量建议列表，不再使用占空间较大的三列卡片。
- 会话抽屉采用更紧凑的“新会话 → 会话 → 设置”层级，字体、间距和按钮密度适配手机屏幕。
- 服务商管理改为列表与详情两级；自动模式中可以直接打开当前图片服务商的编辑页调整图片模型、画质、比例和清晰度。
- 图片模型、对话模型优先从接口返回的模型列表选择，手动填写保留为次级入口。

## 自动路由安全

- 图片只是示意、文件分析、图片工作流咨询和“生成提示词”等请求继续走对话 API，不会误扣生图费用。
- “把这张图变成赛博朋克”等明确编辑请求会识别为图片编辑。
- 明确要求生图时仍先经过独立对话 API 整理作图要求，再调用图片 API。

## 发布

这是 Android `versionCode 11` 的覆盖安装版本。APK、SHA-256、安装说明和隐私说明见 GitHub Release 页面。
