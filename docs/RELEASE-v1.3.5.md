# Salcara AI v1.3.5

## Cherry / ChatGPT 风格简化

- 默认使用一个统一对话入口：聊天、文件分析、图片理解和明确的生图/改图请求都在同一会话中完成。
- 自动模式收窄为顶部轻量“自动”入口，普通问题和附件分析不会因为上传图片而自动扣生图费用。
- 生图请求仍先交给独立对话 API 整理和确认要求，再调用独立图片 API；图片和对话服务商可以分别配置。
- 服务商编辑页的模型默认使用可选模型芯片，手动填写模型 ID 和默认图片参数收进折叠项，减少长表单。
- 会话顶部显示当前会话标题；“上一张图片”提示明确说明只有写出“生成 / 修改”时才会作为参考图。
- API 地址保存前增加协议校验，避免空地址或无效地址进入本地配置。

这是 Android `versionCode 13` 的覆盖安装版本。APK、SHA-256、安装说明和隐私说明见 GitHub Release 页面。
