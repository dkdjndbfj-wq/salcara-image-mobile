# Salcara AI v1.5.0

Android `versionCode` 为 16，可覆盖安装 v1.3.x，会话、服务商与密钥都会保留。本版包含原计划 v1.4.0 的全部内容。

## 全新体验

- **真正的 Agent**：同一个对话里想聊就聊、想画就画。对话模型通过工具调用自己决定何时画图、改图，说“把刚才那张改成夜景”即可，不再有模式切换和“接着上一张创作”。
- **语音输入**：输入框新增麦克风，边说边出字。三档本地离线模型——极速 Zipformer、均衡 Paraformer（推荐）、精准 SenseVoice（自带标点，支持中英日韩粤）——可在“设置 → 语音”自由下载、切换、删除，支持国内镜像；也可以使用你自己选择的云端识别 API。
- **Live 语音对话**：顶部栏常驻 **Live** 按钮（输入框为空时右侧也有），一点即进入沉浸式语音对话；还没配置对话模型时会提示去添加。极光随你的声音起伏、思考时流转、回答时变暖跳动，大字幕实时显示，说话或点按屏幕即可打断。
  - 分段语音：语音识别 API → 你的对话模型 → 语音合成 API（也可用手机系统语音在本机朗读），还能在对话里继续画图，内容保存进会话。
  - 实时语音模型：支持 OpenAI Realtime、Azure OpenAI、阿里云 Qwen-Omni、Gemini Live、阶跃星辰，延迟更低；连不上时自动改用分段语音。
- **一个功能一个 API，服务商随你搭**：Salcara 不提供任何模型或语音服务，所有云端能力都调用你自己的 API，而且每个功能可以用不同的服务商——比如对话用 DeepSeek、画图用豆包、朗读用 OpenAI、识别用阿里云。
  - 添加 AI 服务时可一键选择 DeepSeek、通义千问、豆包（火山方舟）、Kimi、智谱 GLM、MiniMax、硅基流动、阶跃星辰、百度千帆、腾讯混元、OpenAI、Claude、Gemini、Grok、Mistral、Groq、OpenRouter，自动填好地址和接口类型，并有“获取 API Key”直达链接。
  - 在“设置 → API 管理”里添加一次平台（只填地址和密钥），对话、绘图、语音都能直接选用。支持阿里云百炼（Qwen-ASR / Qwen-TTS / Qwen-Omni）、火山引擎豆包语音、硅基流动、智谱、MiniMax、阶跃星辰、百度智能云、OpenAI、Azure AI 语音、Azure OpenAI、Google Cloud、Gemini、ElevenLabs、Deepgram、Groq、Fish Audio 及任意 OpenAI 兼容服务；语音识别、语音合成、实时语音各自选择服务、模型和音色。
- **助手 Live 开场与常驻人物**：每次启动后第一次进入 Live 会播放电影片头式开场——光从底部升起，镜头穿过星空，闭着眼的她从虚焦中显现，标志由柔光凝聚、扫过高光，彗星绕环一圈，然后她**睁开眼睛**、眼中一闪；之后再进入是约 1.5 秒的精简版，点屏幕可跳过。对话时她会一直留在画面里：不时眨眼，思考时闭上眼、轮廓光缓缓呼吸，说话时轮廓光随声音起伏。
- **全新界面与品牌**：新 Logo（矢量）与开机动画，图片生成后从极光中“显影”，并可一键“换个风格 / 改成横版 / 再来一张 / 加点细节”。
- **多个对话同时进行**：一个对话在画图时，可以切到别的对话或新建对话继续聊；侧边栏用呼吸圆点标出进行中的对话。
- 长按自己的消息可以复制或编辑后重新发送；回答里的网址可以直接点开；回复进行中也能继续添加附件。

## 聊天空间与「记忆匣」

- **两个空间，一键切换**：顶部“助手 | 聊天”切换，从点按处绽开一道蓝紫色光晕转场进入另一个界面。助手空间负责提问、画图、查资料和办事；聊天空间是和角色像朋友一样聊天，星光蓝紫配色、短句回复，界面与会话完全分开，各自记住上次打开的对话。
- **多个角色**：内置暖暖、阿怼、小橙、林深四个模板，也可以自己写人设、说话风格、关系和开场白，单独指定模型。角色能看你发的图、帮你画图、联网查资料，也能进 Live 语音对话。
- **没有对话上限**：每个角色一条无限长的对话。较早的聊天会自动折叠成“往事”摘要，往事多了再逐层合并（参考 MemGPT / Letta 的分层记忆），模型每次只带核心记忆、往事、此刻想起的事和最近的原话，聊多久都不会“失忆”或超长。
- **记忆匣**：每个角色都有自己的记忆匣。聊天后在后台把值得记住的事整理成记忆卡片（人物、喜好、事件、计划、一起做过的事、心情……），发现事实变了会把旧卡片标为“已过时”并连到新卡片（参考 Mem0、Graphiti），卡片之间自动连线（参考 A-MEM），隔一段时间还会反思出“感悟”（参考 Generative Agents）。
- **记忆画布**：像 Obsidian 一样的无限画布，双指缩放、拖动，点开任一卡片查看、编辑、设为核心、标记过时或删除；另有时间线和可搜索的列表。回复下方的“想起了 N 件事”可以直接在画布上高亮这次回忆的路线。
- **回忆更准**：中文分词 + BM25 关键词检索，配合可选的云端向量（默认 text-embedding-3-small），再沿着连线扩散联想，并综合重要度与新鲜度排序。
- **导出到 Obsidian**：一键把记忆匣导出为带双链的 Markdown 仓库压缩包。
- **聊天 Live 独立**：聊天里的 Live 是另一个房间——明亮的通话界面以角色头像为中心，说话时声波光环向外扩散、头像随声音轻轻摆动，思考时有星点绕着头像转，用的是这个角色的人设和记忆。
- **头像可换**：可以从相册选、拍一张（自动裁成方形），或挑一个表情。
- **更有趣的聊天**：切换到聊天时从手指处迸出爱心和气泡，中间冒出一个“正在输入”的气泡；新消息弹簧式弹出；**双击消息点亮 ❤️**，长按弹出表情回应（❤️😂🥺😮👍🔥）和复制、重发；**双击 TA 的头像“拍一拍”**，TA 会俏皮地回应；说“晚安、生日快乐、爱你、新年快乐”等会下一场表情雨；TA 打字时头像会轻轻跳动，背景有随角色颜色流动的柔光。
- **可控**：可按角色选择“自动记住 / 只在我说‘记住’时 / 不记”，可以清空记忆匣；“设置 → 插件 → 记忆匣”可关闭整个功能、选择整理用的模型与向量服务、开关反思。聊天空间的记忆默认与助手隔离；打开“让助手参考”后，助手只能读取标为“关于你”的卡片，不能修改。

## 更聪明的助手（Agent）

- **多步工具**：模型可以连续使用多个工具——先搜索、再读网页、再画图或整理成文件——回答上方有可展开的步骤时间线（“搜索 3 次 · 阅读 2 个网页 · 画了 1 张图”），失败的步骤会标出原因。支持 OpenAI Chat Completions、Responses 与 Claude 三种接口；不支持函数调用的中转站自动改用文字协议。每轮最多 8 步（深度研究 24 步），搜索、读网页、作图都有次数上限，费用可控。
- **联网搜索与引用**：官方 OpenAI（Responses）和 Claude 接口使用服务商原生搜索；其他情况可填 Tavily / Brave 密钥或 SearXNG 地址，都没有时使用内置免费搜索。回答里的 [1] [2] 可点开原文，底部列出全部来源。不读取局域网地址。
- **深度研究**：“+”菜单或首页开启。先列出研究计划并实时打勾，多轮搜索阅读原文，最后写成带来源的报告。
- **记忆与个性化**：“设置 → 个性化”可填写“关于我”和“回答风格”；说“记住……/忘掉……”即可管理记忆，也能在设置里查看、编辑、删除或关闭。记忆只保存在手机上，不会记录密码、卡号等敏感信息。
- **追问建议**：回答后给出 2～3 个一键追问。
- **手机操作**：设闹钟、倒计时、加日程、写短信 / 邮件、拨号、导航、打开网址、分享文字。助手只会生成确认卡片，你点“确认”后才打开系统应用。
- **生成文件**：表格（CSV，Excel 可直接打开中文）、Markdown、网页等，可在应用内预览、复制、分享保存。
- **历史对话搜索**：侧边栏搜索可以搜到消息内容；助手也能在你提到“之前聊过的”时查找历史对话。
- **画图自检（可选）**：画完让模型看一眼成图、指出问题，或在明显不符合时自动重画一次（“设置 → 工具与联网”，默认关闭）。

## API 与模型：两步说清楚

- **API 管理**只填地址和密钥：选平台 → 填密钥 → 连接（自动读取模型列表验证）。所有平台（对话、绘图、语音）在同一个列表里，同一平台多个 Key 可分别添加并自动编号区分。少数语音平台才需要的额外项（APP ID、实时地址等）收在“高级选项”里。
- **选模型**统一为 ① 选 API → ② 选这个 API 的模型：对话 / 绘图在全新的“切换模型”页（分“对话 / 绘图”两栏，模型直接在页面里搜索点选，也可手动填写），语音识别、合成、实时语音在“语音”页，音色跟在模型下面。语音不再默认固定为 GPT 模型：跟随对话 API 时用该平台自己的默认模型。
- 对话模型由助手和聊天空间共用（角色不再单独设置模型）。
- 聊天空间右上角新增“设置”入口，与助手空间是同一套设置。
- 旧版单独添加的“语音服务”会自动迁移成普通 API，密钥一并保留。
- 去掉了首页“来点灵感”和“智能体”入口，界面更简洁。
- 助手 Live 的开场只保留星空与标题文字，开场结束后文字淡出，对话时只留星空背景。

## 改图不再被“加戏”

- 新增“作图描述”（切换模型 → 绘图 → 出图设置），默认 **用我的原话**：你怎么说，就原样交给绘图模型，GPT Image 这类会自己思考的模型不再被对话模型改写、扩写后的提示词带偏；改图时只传你要改的内容和原图。只有你提到“按刚才的方案”“按附件”“再来一张”等依赖前文的话时，才在你的原话后面补上必要的前文内容。
- 想要以前的效果，可选 **让 AI 帮我扩写**（适合不会自己思考的绘图模型）。“画完后检查 / 自动重画”也移到了这里。

## 设置更简单

- 设置页整理成三组：模型与 API、个性化、其他。
- “记忆匣”设置精简为“聊天记忆”两个开关：整理记忆自动用当前对话模型，向量检索自动用对话 API 自带的 Embeddings（OpenAI、通义、智谱、硅基流动、Gemini 等），不再需要手动选择服务商和模型。
- “工具与联网”改为“联网与手机操作”：一个“允许联网”开关即可，其他搜索服务和密钥收进“更换搜索服务（一般不需要）”。
- “关于与反馈”改为反馈交流 QQ 群：881490534。

## 首次安装引导

- 全新的 5 页引导：认识 Salcara、两个空间（助手 / 聊天）、“一个功能一个 API”、Live 语音，最后一页是“准备就绪”清单——连接对话服务、添加绘图模型、设置语音，完成一项打一个勾，连上对话服务就能开始。可随时跳过，只在第一次安装时出现。

## 画幅比例随心选

- 画幅不再只有 1:1 / 16:9 / 9:16：新增自动、3:4、4:3、2:3、3:2、4:5、21:9、1:2、3:1，还能自定义任意“宽:高”（如 2.39:1），范围 1:3～3:1。
- 尺寸按模型自动换算：GPT Image 2 支持任意尺寸（宽高为 16 的倍数、最长边 3840、最高约 830 万像素），1K / 2K / 4K 分别对应约 100 万、420 万、830 万像素；GPT Image 1 / 1.5 / mini 与 DALL·E 只支持固定尺寸，会自动匹配最接近的比例并在设置里说明；其他模型按 64 像素对齐。
- 对话里说“做成手机壁纸”“21:9 电影感”“横幅”，助手会为那一张选合适的比例。
- 以前的“横版 16:9”实际发送的是 3:2（1536×1024），现在是真正的 16:9。

## 无限长对话、随时换模型

- **不再限制对话长度**：去掉了“最近 12 轮”和“12 万字”的上限。每次按当前模型的上下文大小携带尽量多的原文；更早的内容在回答完成后于后台整理成“滚动摘要”（用你当前的对话模型，只有积累到一定长度才会整理一次），之后每轮都带上，模型依然记得前情。只有“单条消息本身”超过模型能读的长度时才会提示拆分发送。
- **对话中途换模型 / 换服务商**：历史按中立格式保存、每次按新服务商的协议重新组装，所以直接切换即可继续聊。换到上下文更小的模型时，会先把放不下的部分补进摘要再发送；换到不能看图的模型时，自动把历史图片换成文字说明并重试一次，之后记住这个模型不再发图。消息列表里会出现“以下由 X 回答”的分隔线。
- **思考模型的工具调用更稳**：DeepSeek、Kimi 等思考模型的推理内容、Gemini 的思维签名会在同一轮的工具调用中原样回传，避免多步工具时报错。
- **重新生成更安心**：重新生成使用当前选中的模型；如果失败或被停止，原来的回答会恢复，不会丢失。

## 修复

- API 地址：带版本号的地址（火山方舟 /api/v3、智谱 /api/paas/v4、Gemini /v1beta/openai、千帆 /v2 等）不再被错误地追加 /v1；已保存的错误地址会自动修正。修改服务商地址到另一个服务时，不会再把旧密钥发给新服务。
- 实时语音：点按打断后不再继续播放被打断回答的残余音频；Gemini Live 不再把回声误判为插话；连接断开时释放麦克风和常亮；密钥无效、模型不存在、额度不足会给出明确提示。
- 分段语音：云端识别 20 秒、单句合成 30 秒超时；关闭 Live 后迟到的识别结果不会再被发出；麦克风出错会停在错误页而不是假装在听。切换语音服务时模型与音色重置为该服务的默认值；已删除的服务商自动回退到当前对话服务商。
- 聊天空间：快速连点角色不会重复创建对话；没有打开角色时的消息不会跑进助手对话；后台整理记忆只改动相关字段，不会覆盖你刚做的编辑；删除角色后不会残留记忆卡片；表情雨和爱心动画不再被中途截断；被遮挡或切到后台时暂停氛围光动画。
- 网页读取：手动跟随跳转，公开网页无法再把请求跳到局域网地址；Claude 模型列表一次读取完整。
- 画图：只有 GPT Image 模型才发送质量、格式、透明背景参数，其他模型（DALL·E、Seedream、通义万相等兼容接口）不再因未知参数报错。
- 提示条最多三行、不再溢出屏幕；弹窗在键盘弹出时自动上移。
- 语音：实时语音按服务端轮次配对问答，迟到的转写也能对上；通义实时语音会转写你说的话；语音输入按各服务的时长上限自动分段，识别失败时保留录音、再点一次麦克风即可重试；语言代码按各家接口自动转换；重采样跨分片连续，不再有咔嗒声；同一轮只提示一次语音合成失败。
- 本地识别模型不可用时 Live 会自动改用云端识别并提示，而不是直接失败。
- 画图：异步任务轮询遇到网络抖动会自动重试，重试时接着查原任务，不会重复提交扣费；重画失败或被停止时保留原来的图片。
- 输出被长度限制截断时不再执行不完整的工具调用；错误提示会说明是哪一步出错（读取附件 / 对话模型 / 绘图服务）。
- 界面：标题栏更清爽（标题 + 模型两行显示），文字对比度更高，小按钮更好点，流式输出更省电，按返回键可取消语音输入，图片预览关闭不再闪烁，清除搜索密钥前会确认，涂抹说明改为“蓝色区域”。
- 修复一个可能导致启动时崩溃的问题。

## 界面

- 全新图标：统一的圆润线条加柔和双色调，更精致也更易辨认。
- 按钮、标签、弹窗、提示、设置列表全面升级：主按钮带渐变高光，列表图标放进彩色小方块，弹窗和提示更通透。

## 更稳、更省

- **不会重复扣费**：生图请求只有在确定没有发出（域名解析、连接失败）时才会换一条线路重试；连接中途断开不再自动重发，避免同一张图付两次钱。
- **删除服务商不再删除对话**：旧版本删除最后一个服务商会连带删除全部会话，现已修复，升级时自动迁移数据库。
- 等待超时（10 分钟）会明确提示“图片可能仍在服务商处生成”，不再显示成“已停止”。
- 生成中被关闭的应用：已经写出的文字会保留。
- 重新生成图片、删除进行中的对话、废弃的草稿附件都不会再留下占用空间的文件；启动时自动清理无人引用的旧文件。
- 切换对话时草稿（文字和附件）按对话保留，切回来还在。
- 流式输出更可靠、更顺滑；追问同一份 PDF / Office 文件时复用已解析内容，不再每轮重新处理。
- 通知提示在弹窗和图片预览上方也能看到；涂抹区域重新打开会保留；“拍照提问”直接打开相机；设置子页面返回回到设置。
