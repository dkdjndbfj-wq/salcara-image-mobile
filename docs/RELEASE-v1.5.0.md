# Salcara AI v1.5.0

Android `versionCode` 为 16，可覆盖安装 v1.3.x，会话、服务商与密钥都会保留。本版包含原计划 v1.4.0 的全部内容。

## 全新体验

- **真正的 Agent**：同一个对话里想聊就聊、想画就画。对话模型通过工具调用自己决定何时画图、改图，说“把刚才那张改成夜景”即可，不再有模式切换和“接着上一张创作”。
- **语音输入**：输入框新增麦克风，边说边出字。三档本地离线模型——极速 Zipformer、均衡 Paraformer（推荐）、精准 SenseVoice（自带标点，支持中英日韩粤）——可在“设置 → 语音”自由下载、切换、删除，支持国内镜像；也可以使用服务商的云端语音识别。
- **Live 语音对话**：输入框为空时点右侧的 Live 按钮进入沉浸式语音对话。极光随你的声音起伏、思考时流转、回答时变暖跳动，大字幕实时显示，说话或点按屏幕即可打断。
  - 分段语音：任意对话模型 + 语音合成（云端或手机系统语音），还能在对话里继续画图，内容保存进会话。
  - 实时语音模型：OpenAI Realtime（默认 gpt-realtime-2.1），延迟更低；连不上时自动改用分段语音。
- **全新界面与品牌**：新 Logo（矢量）与开机动画，首页“来点灵感”，图片生成后从极光中“显影”，并可一键“换个风格 / 改成横版 / 再来一张 / 加点细节”。
- **多个对话同时进行**：一个对话在画图时，可以切到别的对话或新建对话继续聊；侧边栏用呼吸圆点标出进行中的对话。
- 长按自己的消息可以复制或编辑后重新发送；回答里的网址可以直接点开；回复进行中也能继续添加附件。

## 更稳、更省

- **不会重复扣费**：生图请求只有在确定没有发出（域名解析、连接失败）时才会换一条线路重试；连接中途断开不再自动重发，避免同一张图付两次钱。
- **删除服务商不再删除对话**：旧版本删除最后一个服务商会连带删除全部会话，现已修复，升级时自动迁移数据库。
- 等待超时（10 分钟）会明确提示“图片可能仍在服务商处生成”，不再显示成“已停止”。
- 生成中被关闭的应用：已经写出的文字会保留。
- 重新生成图片、删除进行中的对话、废弃的草稿附件都不会再留下占用空间的文件；启动时自动清理无人引用的旧文件。
- 切换对话时草稿（文字和附件）按对话保留，切回来还在。
- 流式输出更可靠、更顺滑；追问同一份 PDF / Office 文件时复用已解析内容，不再每轮重新处理。
- 通知提示在弹窗和图片预览上方也能看到；涂抹区域重新打开会保留；“拍照提问”直接打开相机；设置子页面返回回到设置。

## 权限

新增麦克风权限，只在语音输入和 Live 对话时使用。本地模型的声音只在手机上处理；使用云端语音时，录音只发送给你选择的服务商。
