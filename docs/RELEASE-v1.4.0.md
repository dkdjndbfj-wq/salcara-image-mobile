# Salcara AI v1.4.0

Android `versionCode` 为 15，可覆盖安装，本机会话、服务商与密钥都会保留。

- **真正的 Agent**：对话模型通过工具调用自己决定何时画图、改图，不再依赖关键词判断，也不需要切换模式或“接着上一张创作”。说“把刚才那张改成夜景”即可。
- **流式回复**：三种协议都逐字显示；不支持工具调用的中转自动降级为文本协议。
- **修复**：连续点击“新对话”不再在侧边栏生成多个空会话；新对话在发送第一条消息前不会写入数据库，旧版本遗留的空会话会在启动时清理。
- **全新界面与品牌**：全新 Logo 与启动图标；自绘 SVG 图标集替换图标字体；欢迎页、首页、聊天、输入框、侧边栏、模型面板、设置与服务页面全部按商业级产品重做，加入思考、柔光绘制、流式与弹性动效。
- 移除“创作技能”与“引用创作”；删除服务商时保留已有对话。
- **多对话并行**：一个对话在画图时可以随时切到别的对话或新建对话继续聊，后台任务不会被打断；侧边栏用呼吸圆点标出仍在进行的对话，“停止”只作用于当前对话，删除对话会同时停止它的请求。
- **PDF 更省**：追问同一份 PDF 时复用已渲染的页面（内存上限约 16MB），不再每轮重新渲染；历史中只有最近两轮带附件的内容会重新附带原文，更早的只保留文件名提示，历史 PDF 无法读取时不再阻塞当前提问。
- **开机动画**：从系统启动图无缝接入——彩光在 Logo 后晕开，四条丝带轻轻舒展并旋转半圈，“Salcara”字标逐字浮现，随后标志先淡出、白色幕布再揭开进入首页，首页内容在揭开时依次入场。全程约 1.8 秒，开启“减少动态效果”时仅做短暂淡出。
- **矢量 Logo**：新增 `assets/brand-logo.svg`，应用内所有 Logo 改为矢量绘制，任意尺寸和深色背景下边缘都干净。
- **流式输出更可靠、更顺滑**：系统缺少 TextDecoder 时改用内置 UTF-8 解码（中文和表情跨数据块不会乱码），不再退化为整段一次性显示；兼容 ArrayBuffer 数据块与跨块的 CRLF；文字以匀速打字机效果呈现，网络成批到达时自动加速追上，结束时平滑收尾。
- **首页“来点灵感”**：14 个创意主题随机抽 4 个，每张卡片都有独立的渐变插画，可“换一批”；下方为改照片、读文件、拍照提问等快捷入口。
- **图片完成后**：图片从绘制时的极光画布中“显影”出来并带一道柔光扫过；最新一张图下方提供“换个风格 / 改成横版 / 再来一张 / 加点细节”，一键继续创作。
- **语音输入**：输入框新增麦克风，边说边出字。可选三档本地离线模型（极速 Zipformer / 均衡 Paraformer / 精准 SenseVoice，设置里自由下载、切换、删除，支持国内镜像），或使用服务商的云端语音识别。
- **Live 语音对话**：输入框为空时发送键变为 Live 按钮，进入沉浸式语音对话——极光随你的声音起伏、思考时流转、回答时变暖跳动，大字幕实时显示，说话或点按即可打断。支持“分段语音”（任意对话模型 + 语音合成，可继续画图、记录进对话）与“实时语音模型”（GPT Realtime，更低延迟），自动选择与回退。详见 `docs/VOICE.md`。
