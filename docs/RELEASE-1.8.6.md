# Salcara Android 1.8.6

本版修复远程连接、审批回执和任务恢复问题，配套 **Salcara Desktop 1.6.9** 与 **Salcara Hub 0.5.6**。

- 改善慢网络下的站点发现与身份确认，减少正常响应被过早判为超时；保留地址轮换、取消和站点身份校验。
- 修复重新扫码期间旧绑定错误回包干扰新配对，以及旧会话回包覆盖当前连接状态的问题。切换站点身份后，旧请求不再继续发送；绑定已失效时明确提示重新扫码。
- 审批或停止请求回包丢失时，保留原请求并核对结果，避免重复授权或重复操作；切换会话、离开页面和后台恢复时按原会话处理。
- 改善 Hermes 历史工具事件、审批结果和首次问答能力的识别；来源不可继续使用时保留历史与草稿，并提供新建会话入口。
- 支持在配套 Hub 上撤回尚未派发的任务，断线后先核对原任务状态；已执行的任务恢复原结果，不重新发送。

正式包名仍为 `top.salcara.image`，版本 1.8.6（Android versionCode 27；iOS 源码 buildNumber 27）。Android 构建沿用现有正式签名，以 1.8.5 为覆盖升级对照版本。新包可直接覆盖安装正式旧版。

## 使用边界

任务撤回和 Hermes 问答按电脑及 Hub 实际支持能力开放。“暂停重试”只暂停后续重试，当前请求仍可能完成；界面会继续保留并核对原请求状态。

电脑需自行安装并配置相应 Agent，本版不接管 Claude 账号登录。Android 后台通知受系统、省电、网络和站点配置影响；实际安装、锁屏、省电、真实推送与 Agent 使用体验仍需在实际设备确认。本版不提供新的正式 iPhone 安装渠道。
