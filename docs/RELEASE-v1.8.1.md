# Salcara AI v1.8.1

Android ARM64 / ARMv7 正式修复版。包名保持 `top.salcara.image`，版本 1.8.1 / versionCode 22，沿用已有正式签名，可直接覆盖安装。

- 绑定新电脑直接扫码，从二维码识别 Hub 地址。
- 改善同一电脑跨中转站配对、解除绑定与 API/Hub 交接恢复。
- 修复会话读取、历史分页、断线重试及旧请求覆盖新连接的问题。
- 修复取消历史分页后一直转圈；切后台取消读取，回前台恢复，不清草稿或重复发送。
- 保留原有界面与动效；其他功能保持不变。
- 对齐 Expo SDK 57 的四个补丁依赖，恢复完整 SDK 兼容检查。

建议配合 Salcara Desktop 1.6.2 和 Hub 0.5.1 使用。不要先卸载旧版，以免丢失本机数据。

长离线后需要电脑恢复在线才能重新读取权威历史。切站要求目标 Hub 已配对；当前 Hub 在交接前彻底不可达时，尚不支持独立备用通道切站。远程不是屏幕投影，Claude Desktop 原生 Chat/Cowork 仍只读，Codex 原生发送需要有效授权。本次不提供正式 iOS 安装包。
