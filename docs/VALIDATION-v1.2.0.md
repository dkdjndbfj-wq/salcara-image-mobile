## 单次真实生图

管理员确认在 sub2api 中开启「生图结果 URL 转 base64」后，经明确许可使用 Salcara 下游测试配置调用一次：

- 提示词：奥特曼打怪兽。
- 模型：gpt-image-2.5-sunburst；画质：max。
- 请求尺寸：1024×1024，PNG，1 张。
- HTTP 200，接口等待 46.068 秒，无重试。
- 返回包含非空 `b64_json`（同时保留 `url`），客户端优先使用 Base64 保存，不必连接外部图床。
- 保存结果有效，为 1254×1254 PNG；已进行视觉检查。实际尺寸由上游决定，不是客户端放大所得。
- 无密钥或原始响应保存在本仓库。

## 验证边界

该实测是电脑 CLI/API 验证，并非受影响 Android 手机的运营商网络测试。文字对话及 PDF 使用模拟接口测试，尚未对用户配置的真实多模态模型付费验收；只有支持对应输入的模型／分组才能使用。

本地没有连接 Android 真机；签名、包名与 versionCode 升级兼容性由发布工作流检查。安装、键盘、相册、文件选择和实际运营商网络仍需在受影响手机上验收。GitHub 下载站点可达性独立于 Salcara API，不能以本次生图成功推断 APK 下载必然可用。
