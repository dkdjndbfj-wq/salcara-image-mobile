# Salcara Image v1.2.1

- 新增独立的文字对话、图片理解与文档解析。生图和对话 API 各自配置地址、密钥、模型。
- 支持 Chat Completions、Responses、Claude Messages；同一会话可讨论生成结果。
- PDF 在 Android 本地逐页转图后交给视觉模型，避开部分中转接口成功返回却忽略文档的问题。每份最多 12 页、最长边 1600 像素；超限请拆分，绝不静默截断。
- 支持 PDF、TXT、Markdown、CSV 辅助生图：先解析，再生成；两步分别计费。解析结果持久保存，重试生图不重复解析。
- 改善图片下载超时与取消：保留原链接，重新下载不重复生图。新增免费的网络诊断。
- 更新检查使用正式发布清单；APK 采用流式下载并验证 SHA-256 后安装。
- 原有会话、图片与密钥保持兼容，Android versionCode 为 7。

sub2api 运营者建议开启上游账号的「生图结果 URL 转 base64」。已用 Salcara 下游实测开启后收到内嵌图片，手机无需连接返回的外部图床。不同运营商的 API／GitHub 下载可达性仍需实测，不保证所有网络都可直连。

请直接覆盖安装，不要卸载旧版。配置与隐私说明见仓库 README 和 PRIVACY.md。v1.2.0 的构建在 PDF 验收发现兼容问题后已撤销，未发布 APK；本版包含其全部功能。
