# Salcara AI v1.3.1

这是 v1.3.0 通用 AI 客户端的稳定性补丁。

## 主要修复

- 兼容更多 OpenAI 兼容网关的图片响应包装（`b64_json`、`image_base64`、`partial_image_b64`、`result.data`、内嵌 data URL 等），并优先使用内嵌图片内容。
- 支持 Sub2API 异步图片任务返回的 `task_id`，在同一 API 地址安全轮询，不重新提交收费请求。
- 将 HTTP/2 `StreamResetException: CANCEL`、图片 CDN 超时和 API 连接失败分开提示；已生成但下载失败时只提供“重新下载”，不会再次生图扣费。
- 图片服务商与对话服务商在配置界面明确分离，图片服务商可以只配置 Images API；对话模型在弹层中通过列表选择，手动填写收进折叠项。
- 缩小标题、消息、服务商和弹窗字号，统一紧凑的白色/浅蓝界面。
- 同步补充网络排障说明，提示在 Sub2API 每个生图上游账号开启“生图结果 URL 转 base64”。

## 计费与安全

应用不会因为“没有图片数据”自动重新提交一次新的付费生图请求。生成请求是否已经计费，应以服务商记录为准；只有拿到外部图片 URL 后的下载重试不会重复调用生图接口。

APK 与 `.sha256` 文件由 GitHub Actions 生成并发布，更新清单只在发布成功后写入 `updates` 分支。
