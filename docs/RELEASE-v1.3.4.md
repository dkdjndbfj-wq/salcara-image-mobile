# Salcara AI v1.3.4

## 更保守的自动生图判断

- “帮我生成图片提示词”“生成图片需要什么参数”“把文字改得更正式”等普通对话不会触发生图扣费。
- “把这张图变成赛博朋克风格”“将背景改成蓝色”等明确图片编辑请求仍会自动进入图片编辑流程。
- 继续保留图片附件仅用于分析时的对话路由，以及生图前先由对话 API 整理要求的安全步骤。
- 自动模式的网络诊断会分别探测对话服务商和图片服务商，避免把“对话能连通”误认为“图片接口也能连通”。

这是 Android `versionCode 12` 的覆盖安装版本。APK、SHA-256、安装说明和隐私说明见 GitHub Release 页面。
