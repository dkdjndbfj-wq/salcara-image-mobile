# Salcara Android 1.8.4

本版完善手机端连接电脑和新建会话流程，配套 **Salcara Desktop 1.6.6** 与 **Salcara Hub 0.5.4**。

- 全局“新会话”先选 Agent，再浏览电脑的本地磁盘和文件夹；选定父位置并命名新文件夹后进入编辑器，也可以选择“不关联文件夹”。新页面沿用手机编程主页的 Agent 卡片、浅灰画布和分组样式。
- 项目内“新建会话”直接继承当前 Agent、Code/Work 和精确项目路径。浏览目录不会启动任务，首次发送消息才创建会话；取消或切换电脑后，迟到的目录结果不会打开错误的项目。
- 电脑新建目录遇到同名、权限不足或结果未确认时明确提示，不覆盖已有目录、不自动重复创建。新建目录的授权仅限该目录，重启后仍会核对目录身份与授权状态。
- 将手机配对与模型 API 凭证分开；完善带路径的 Hub 地址发现和签名身份校验。站点来源权限或电脑身份错误不再一律当作手机配对失效，避免误删有效连接与待恢复任务。
- 直连与 Hub 中继使用一致的新会话语义，保留无文件夹会话的明确标记、草稿归属和发送回执；修复直连新会话页面重复导航栏。

正式包名仍为 `top.salcara.image`，版本 1.8.4（Android versionCode 25；iOS 源码 buildNumber 25）。正式 Android 构建沿用现有发布签名，并核验与 1.8.3 的覆盖升级兼容性。已安装正式版时无需先卸载。

## 使用边界

全盘浏览和无文件夹会话需要配套电脑端及相应 Hub 能力；旧版缺少能力时会给出更新提示。只浏览电脑上实际可用的本地磁盘，目录访问受电脑系统权限限制，不会自动提权；网络盘不作为本地磁盘使用。

各 Agent 的发送、模型、历史和工具能力依其实际支持情况开放。Android 后台恢复和推送仍受系统、省电策略及站点配置影响，不能保证进程被强制停止后即时送达。本版不提供新的正式 iPhone 安装渠道。
