# Salcara AI v1.6.1

Android `versionCode` 为 18。可覆盖安装 v1.6.0；服务商、密钥、会话和本地文件保留。

## 服务商与设置

- 重新整理 API 管理：按服务商保存地址和密钥，对话、绘图、语音识别、语音合成及实时语音分别选择使用哪个服务和模型。
- 新增常用服务商目录、功能选择器与统一设置入口；助手和聊天空间可使用同一套配置。
- 旧语音服务配置在升级后迁移到统一的 API 服务列表。

## 界面与维护

- 调整模型切换、角色聊天、记忆匣、工具和语音设置界面。
- 移除不再使用的 Live 图片资源、旧灵感组件和旧语音服务占位文件。
- 修复语音测试夹具的兼容问题，并通过类型检查与自动化测试。
