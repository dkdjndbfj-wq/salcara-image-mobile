# 远程配套

手机的远程客户端实现位于 [src/remote](../src/remote)，用户操作见 [远程编程教程](../docs/REMOTE-PROGRAMMING.zh.md)。

配套组件已独立维护：

- [Salcara Desktop](https://github.com/dkdjndbfj-wq/salcara-desktop)：电脑上的 Agent、API 与项目。
- [Salcara Hub](https://github.com/dkdjndbfj-wq/salcara-hub-plugin)：Docker 部署、设备配对与消息中继。

请从上述正式项目下载或部署，不在手机源码目录里构建服务器或桌面组件。手机仓库只包含完整的手机应用；旧组件源码可从 Git 历史恢复，不再维护第二套内核。
